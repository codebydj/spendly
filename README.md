# Spendly

### Premium Personal Finance Tracker

Spendly is a modern, mobile-first personal finance application designed to help users manage their money, accounts, transactions, budgets, recurring payments, and financial insights in one place.

It combines a premium glassmorphic interface with offline-first functionality, Supabase cloud synchronization, multi-account support, analytics, budgeting, and Android support.

---

## 🌐 Web App

**Live Web Application**

https://your-vercel-domain.vercel.app

Spendly can be used directly from a web browser without installing anything.

### Web Features

- 🔐 Secure email/password authentication
- 💰 Personal account management
- 💳 Bank and credit card tracking
- 💵 Cash and wallet management
- 📊 Financial analytics
- 📅 Financial calendar
- 🎯 Monthly budgets
- 🔄 Recurring payments
- ☁️ Supabase cloud synchronization
- 📱 Responsive mobile interface
- 📴 Offline-first support
- 🔔 Notifications and reminders
- 🔊 Optional sound effects
- 🔒 Hide balance / privacy mode

# 📱 Android App

Spendly is also available as an Android application powered by Capacitor.

The Android version provides the same core finance-management experience with native mobile capabilities such as:

- Native Android application
- Haptic feedback
- Native notifications
- Safe-area mobile navigation
- Offline support
- Supabase cloud synchronization
- Same user account across Web and Android

### Android Download

The Android APK can be distributed directly to users without publishing Spendly on Google Play Store.

> The Android APK is generated from the same source code used by the web application.

# ✨ Main Features

## 🔐 Authentication

Spendly uses Supabase Authentication for secure user accounts.

- Sign up
- Login
- Logout
- Password change
- User profile
- Individual user data isolation
- Supabase Row-Level Security

Every user's financial data belongs to their own account.

---

## 💰 Account Management

Create and manage multiple financial accounts.

Supported account types:

- 🏦 Bank Account
- 💵 Cash
- 👛 Wallet
- 💳 Credit Card
- Other account types

Each account maintains its own balance and transaction history.

### Total Net Worth

Spendly automatically calculates the combined financial position across accounts.

Users can also hide their balances using privacy mode.
